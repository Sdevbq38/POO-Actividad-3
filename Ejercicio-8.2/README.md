# Ejercicio 8.2 - Gestión de notas

**Asignatura:** Programación Orientada a Objetos

**Actividad:** 3

**Lenguaje:** Java

## Descripción

Aplicación desarrollada en Java utilizando programación orientada a objetos
e interfaces gráficas con Swing.

El programa permite ingresar cinco notas y calcular:

- Promedio.
- Desviación estándar.
- Nota mayor.
- Nota menor.

## Archivos

- `Actividad3_ejercicio8point2.java`: clase principal.
- `Notas.java`: clase encargada de los cálculos.
- `VentanaPrincipal.java`: interfaz gráfica.
- `VentanaPrincipal.form`: diseño de la interfaz en NetBeans.
